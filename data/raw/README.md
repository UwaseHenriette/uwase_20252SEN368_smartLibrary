# Raw Dataset

## Dataset Name

UIUC Interlibrary Loan Lending Data (2009–2013)

## Original Source

The dataset is provided by the University of Illinois through the Illinois Data Bank.

Dataset link: https://databank.illinois.edu/datasets/IDB-6701059

## Dataset Information

- File format: Excel (.xlsx)
- File size: 50.3 MB
- Period covered: 2009–2013
- Records: 169,890
- Columns: 51

## Storage Note

The original Excel dataset is not stored directly in this GitHub folder because its 50.3 MB size exceeds the GitHub web upload limit.

The original file can be downloaded from the official Illinois Data Bank link above.

The dataset will be used for interlibrary loan and resource-sharing analysis in the Smart Library Circulation and Reservation System project.

Important: The original dataset will remain unchanged. Any cleaning or transformation will be performed on a separate processed copy.
